# ROY Events & Studios

Premium responsive static website for **ROY Event Management** and **Roy Studios**.

## Website sections

- Event Management introduction
- Event Décor & Themes
- Entertainment
- Stage & Lighting
- Food & Catering
- Aesthetics, Logistics & Hospitality
- Roy Studios photography, videography, portfolio, brand and creative production
- Contact, Instagram and WhatsApp actions

## Run locally

Open `index.html` in a browser.

## Deployment

The project is static and ready to publish with GitHub Pages from the `master` branch.
